Latar tersebut membuat saya tertarik melihat teknologi dari beberapa sisi: software yang digunakan orang, sistem yang menjalankannya, dan perangkat keras yang menghubungkannya dengan dunia nyata.

Saya mengeksplorasi **software development, system integration, Linux, networking, hardware, IoT, GIS, dan AI/ML**. Saya juga tertarik pada UI/UX dan desain visual, terutama bagaimana keputusan teknis dan tampilan dapat mendukung pengalaman pengguna.

Saya masih mempelajari beberapa bidang sebelum memilih spesialisasi. Untuk sekarang, saya berfokus memperkuat fundamental, mencoba ide melalui project, dan memahami alasan di balik setiap keputusan implementasi.
